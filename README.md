# 路见资本

路见资本官网：市场总览、热点新闻、A股涨停复盘、产业研究与公开研究档案。首页采用宫墙红与雪白的拟物玻璃界面，以冷白留白、磨砂玻璃和炭灰文字为主，朱红点缀重点操作；首页以中文介绍和快讯、复盘、研究入口为核心，保留红色玻璃球，图卡展示真实股池分布，支持手机阅读。原股市照妖镜保留在 `/mirror/`，入口仅在页尾。

## 本地运行

Node.js 24、pnpm 11.9.0：

```bash
pnpm install --frozen-lockfile
pnpm dev --hostname localhost --port 3000
```

首页与研究页不依赖数据库。游戏和管理功能继续使用已有 D1 配置；不需要为官网重置数据库。

访客打开网站即可阅读快讯、筛选涨停股池、导出结果和保存本机自选，无需登录、申请行情密钥或配置数据源。此云环境的 Node.js 采集脚本需启用已有环境代理：

```bash
NODE_USE_ENV_PROXY=1 pnpm market:update
```

普通开发环境无需设置该变量；不要把代理地址或凭据写进公开配置。该变量适用于 Node 采集，不代表本地 workerd 已能访问源站。

```bash
pnpm test
pnpm lint
pnpm build
pnpm build:pages
```

`build` 生成 Cloudflare/Vinext Worker，`build:pages` 生成 GitHub Pages 静态站点。两者都会先从 Markdown 重新生成研究内容索引。

## 页面与品牌

- `/`：路见资本首页，新闻、涨停复盘、精选研究、关于路见。
- `/research/`：按分类、关键词检索科技周刊、AI前沿与产业专题。
- `/research/[slug]/`：公开研究正文、原始发布日期、依据与来源。
- `/mirror/`：原股市照妖镜，原接口、存档与兑换权益保持兼容。
- `/manage/`：原游戏兑换码管理。

首页不使用演示行情。接口暂不可用时显示明确状态、重试和研究入口，不生成替代股票、涨幅或新闻。已有研究是原仓库的历史文章，日期保留，不包装成当天复盘。

手机端提供固定底部导航、涨停纵向卡片；快讯支持搜索、只看要闻和新消息手动载入。研究页保留筛选条件，文章支持目录与阅读进度。上一轮设计测量保存在 [UX/UI 优化记录](docs/ux-review.md)。

最新工作台支持连板 / 行业图表切换、星标自选和 `Ctrl / ⌘ K` 研究搜索，详见 [市场工作台说明](docs/market-workspace.md)。访问统计暂时搁置，本轮未安装统计脚本。

## 热点新闻与涨停复盘

详细数据来源、口径、更新机制、故障处理及上线检查见 [市场数据说明](docs/market-data.md)。

- 新闻：东方财富公开7×24快讯为主源，失败时自动尝试 NewsNow 的财联社电报、华尔街见闻快讯；保留真实发布时间与原文入口，支持分类筛选。
- 涨停：东方财富公开涨停股池；首板/连板数量、连板梯队、行业分布、个股搜索、排序、筛选结果 CSV。覆盖以实际收录为准，当前已验证包含科创板与北交所股票，不把股池等同于全市场。
- Worker 模式：同源 `/api/market`，60秒缓存，页面每60秒检查更新；支持近30天指定日期。
- GitHub Pages 模式：工作流约每5分钟同步到公开 `market-data` 分支，相关代码首次推送到 `main` 时自动初始化；浏览器每分钟检查最新快照。计划任务及 GitHub 原始文件缓存可能延迟，**不是秒级实时行情**。
- 新闻与股池独立容错；网络、格式或更新失败时保留对应栏目上次成功的数据及原时间。周末展示真实最近交易日，不能将周五数据标成周末数据。

维护者可随时在本地检查公开源并更新快照（网站访客无需操作）：

```bash
pnpm market:update
```

## 内容维护

产业周刊接入科技爱好者周刊与中文 AI 论文周报，每天北京时间 08:17 自动检查并发布新内容。卡片进入站内导读、产业观察与篇目目录，原刊链接保留在页尾；详见 [产业周刊更新说明](docs/periodicals.md)。可运行 `pnpm periodicals:update` 手动采集。

站内专题来自 `content/articles/` 与 `content/mainline/`。仅 `status: published` 且公开访问的内容进入研究页；其他草稿与会员预览不公开正文。A股市场复盘已从研究页及文章路由移除，源文件保留为历史档案。

更新 Markdown 后运行：

```bash
pnpm content:generate
pnpm build:pages
```

`.pages.yml` 保留 Pages CMS 的内容编辑配置。账户数据、私人交易、客户名单和付费记录不得放入公开文章或公开行情快照。

## 发布

原 GitHub Pages 部署配置和 `public/CNAME`（`baihuzigl.com`）保留。合并到 `main` 后，`Deploy to GitHub Pages` 先恢复公开快照并采集数据，再构建发布官网；若首次采集没有可用数据则停止发布。`Update public market data` 在相关文件推送到 `main` 时自动建立或更新行情分支，后续按 `2-57/5 * * * *` 定时刷新，无需另做一次手动初始化。手动运行入口保留用于维护和恢复。

行情工作流只将 `market.json` 与限制文件列表的 `.gitignore` 写入 `market-data` 分支，避免把工作区文件混入行情发布。仓库需允许工作流写入仓库内容，快照地址须能被访客匿名读取。

2026年10月18日已通过 Node 采集脚本实网验证东方财富快讯40条，以及2026年10月16日涨停股池61只（首板54、连板7、最高11板）。NewsNow 备用源已完成契约与故障切换测试，其域名在本环境仍受代理限制；本地 workerd 的外网 DNS 也尚不可用，不宣称这两条路径已通过实网验收。生产发布以 GitHub Actions 的部署结果为准；上线验收还需核对生产域名的日期、快讯原文和股票明细。
