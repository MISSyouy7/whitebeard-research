# 路见资本市场工作台

布局参考 TradingView 常见的市场工作台结构：紧凑导航与搜索、市场概况卡片、主图表、右侧自选列表。当前环境访问 TradingView 官网受网络规则限制，未核对其最新首页版本；界面由本项目独立实现。

视觉按最新要求改为「故宫墙面红，白色的雪」：雪白（`#F7F8FA`）铺开页面，宫墙红（`#9E3438`）点缀重点操作，炭灰文字保证阅读清晰。首页使用无文字、无虚拟控件的红墙雪景背景，正文与三个主要入口由真实网页元素呈现：热点快讯、涨停复盘、产业研究。品牌、栏目、研究目录均改用中文，移除英文海报、装饰性登录框和日历；保留红色玻璃球作为视觉点缀；桌面首屏玻璃图卡展示真实连板数量，与下方完整工作台共用同一份数据及交易日期，5板及以上合并统计。手机端将数据图保留在下方工作台，避免重复展示。无数据时显示连接状态，不生成示例数值。

页面不再显示行情提供方名称和来源标注；交易日期、更新时间、历史快照状态和股池范围说明保留。新闻标题与阅读全文仍跳转原文。内部保留来源元数据，快讯增加自动备用源，涨停口径按实际收录范围校正。

## 已实现

- 市场总览：展示同一份涨停股池的涨停家数、首板、连板家数与最高连板。
- 交互图表：切换连板分布、数量前六行业；点击、聚焦或悬停图柱查看数量。纵轴从零开始，全部图柱使用相同刻度。图中数量与下方复盘使用同一份数据和交易日期。
- 我的自选：在表格或手机卡片点星标加入或移除；当前浏览器最多保存30只，刷新后保留，同源标签页同步。自选不代表实时全市场行情，仅显示当前股池可匹配的交易日数据。
- 涨停选股：按首板、连板高度、行业、名称或代码筛选，按连板高度或首次封板时间排序，导出当前筛选结果的 CSV。统计与图表使用同一交易日，不将股池筛选包装成收益承诺。
- 全站研究搜索：导航按钮或 `Ctrl / ⌘ K` 打开；输入关键词后跳转研究列表；支持 Esc 关闭和焦点返回。
- 手机布局：单列图表、紧凑自选区、纵向股票卡片与底部导航；研究目录和筛选往返体验保留。

图表呈现股池结构，不是价格 K 线。数据暂时不可用时保留空状态和重试入口，不生成示例价格或数量。截图中的演示行情仅用于交互原型，并在截图顶部明确标注；不会写入公开行情快照。

## 开箱即用的数据

游客无需登录或申请 API key。快讯先读取东方财富公开数据，主源失败时依次尝试 NewsNow 财联社电报、华尔街见闻快讯。备用条目的发布时间来自 `pubDate` 或 `extra.date`，不使用缓存 `updatedTime` 伪造发布时间；无有效时间或最新条目超过24小时则继续回退。

涨停股池采用真实公开数据，实际覆盖包含科创板与北交所，不再以“排除科创板”描述范围。周末保留来源最近交易日：例如2026年10月18日读取的最近股池为10月16日，不标记成周日行情。图卡、完整图表、自选报价和表格共用这一日期。

GitHub Pages 的行情更新约每5分钟执行（cron `2-57/5 * * * *`），相关代码首次推送到 `main` 自动初始化，官网构建也会准备可用的初始快照。行情分支只发布公开快照与文件限制规则，不复制应用工作区。游客只需打开网站，无需手动运行任务。

网络、格式或单个栏目更新失败时，界面尝试可用快照并分别保留已有有效内容及原时间；没有数据才显示连接状态。静态模式每分钟检查快照，超过20分钟显示历史状态，计划任务与文件缓存可能延迟。Worker 模式每60秒自动检查，并提供近30天指定日期查询。两种模式都不将刷新页面的时间当成行情更新时间。

## 登录规划

当前游客无需登录即可浏览快讯、复盘和研究，自选保存在当前浏览器。手机号登录留待跨设备同步自选、收藏或会员功能确定后再设计，本轮不添加登录表单。

## 访问统计

按用户最新要求暂时搁置。未安装 Cloudflare、Umami 或 Google Analytics 访问统计脚本，不需要提供账户或站点标识。

## 验证

原浏览器任务脚本继续验证新闻、复盘、研究、导出、交易日隔离与五种屏宽。新增工作台脚本验证图表数值、自选保存及多标签页同步、快捷搜索与焦点、缺失数据状态，并对研究页和搜索弹窗执行 axe 自动检查。

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs \
AXE_SCRIPT=/absolute/path/to/axe-core/axe.min.js \
UX_OUTPUT_DIR=outputs/palace-snow \
node tests/browser/portal-ux.mjs

PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs \
AXE_SCRIPT=/absolute/path/to/axe-core/axe.min.js \
UX_OUTPUT_DIR=outputs/palace-snow \
node tests/browser/workspace-ux.mjs
```

两个脚本需要先启动开发服务器，默认使用 `http://localhost:3000` 与 `/usr/bin/chromium`。可通过 `UX_BASE_URL`、`CHROMIUM_PATH` 调整。浏览器测试依赖放在独立工具目录，不随生产依赖安装。

上一轮宫墙红与雪白界面验证中，13组浏览器交互通过；320、390、768、1024、1440 px 页面无横向溢出。首页、研究列表、研究正文与搜索弹窗的 axe 检查未发现违规，并已检查首屏图卡与完整工作台的数据一致性及高连板合并统计。这些记录用于说明已验收的界面，后续数据改动需重新运行相关脚本。

2026年10月18日本轮 Node 采集实网检查已取得东方财富快讯40条，以及10月16日涨停股池61只（首板54、连板7、最高11板）。本云环境的 Node 请求需启用 `NODE_USE_ENV_PROXY=1`；这不代表本地 workerd 已连通外网，其 DNS 限制仍存在。NewsNow 备用契约测试通过，但其域名受当前代理限制，尚未完成该备用源的实网验收。

生产发布状态以 GitHub Actions 的部署结果为准。接口机制、故障处理和发布后核对详见 [市场数据说明](market-data.md)。
