# 路见资本 UX/UI 优化记录

这是第二轮刊物风格界面的历史记录。当前 TradingView 风格工作台及最新交互见 [市场工作台说明](market-workspace.md)；下方位置测量不适用于当前工作台版本。

本轮把「读快讯、查涨停、读研究」作为三个主要任务。视觉延续米白、墨绿和少量金色；游戏入口仍只在页尾。

## 设计改动

| 阅读任务 | 原有阻力 | 本轮实现 |
| --- | --- | --- |
| 打开手机首页看新闻 | 品牌首屏较长，快讯在下一屏以后 | 缩短首屏、隐藏手机装饰图；增加快讯和复盘按钮、固定底部导航 |
| 持续阅读快讯 | 更新可能把正在阅读的内容推走 | 新快讯先显示条数，由读者点击载入；支持关键词和只看要闻 |
| 查看涨停股票 | 手机需要横向阅读表格，筛选条件不明显 | 手机采用纵向卡片；次要数据折叠；显示可移除的筛选条件、匹配数量与重置入口 |
| 判断数据是否可用 | 无数据时大量占位数字增加负担 | 骨架屏、明确的重试与来源入口；历史交易日标识；保留有效缓存的真实日期 |
| 查找并阅读研究 | 阅读文章后返回需要重复筛选 | 筛选写入 URL，返回恢复条件；预计阅读时间、目录、阅读进度与文末返回入口 |
| 微信关注 | 需手动记住公众号名称 | 一键复制公众号名称并显示操作结果 |

## 同一视口的前后测量

快讯模块位置是模块顶部距文档顶部的距离；不是加载时间或用户转化率。

| 项目 | 原版 | 新版 |
| --- | ---: | ---: |
| 手机 390×844：快讯模块位置 | 944 px | 436 px |
| 桌面 1440×1000：快讯模块位置 | 804 px | 550 px |
| 手机：新闻分类按钮高度 | 45 px | 48 px |

手机端快讯提前 508 px，约 54%；桌面提前 254 px，约 32%。手机主要按钮至少 44 px，输入字号 16 px；提高辅助文字的对比度，支持键盘焦点和减少动态效果偏好。

## 验证范围与结果

- 浏览器任务检查通过 9 组流程，覆盖导航、新闻筛选和新消息缓冲、涨停筛选与 CSV、断线和交易日隔离、研究往返、空结果恢复、键盘跳转、复制反馈。
- 检查 320、390、768、1024、1440 px 五种屏宽，无页面横向溢出。
- 手机和桌面首页，以及手机研究列表和文章页，通过 axe-core 的 WCAG 2 A/AA、2.1 A/AA 自动规则检查，未检测到违规项。原版手机首页发现的 38 处文字对比度问题已修正。自动检查不等于完整无障碍认证。
- 单元测试 29 项通过；TypeScript、GitHub Pages 静态构建、Cloudflare/Vinext 构建通过。Lint 无错误，原游戏保留 4 条已有图片优化警告。
- 静态发布产物另行通过手机导航、筛选后整页刷新、文章目录与往返检查；未出现 hydration 或运行时错误，也未错误调用 Worker 接口。

测试行情只通过浏览器请求拦截注入；展示有行情的原型截图明确标注「演示数据，非真实行情」。首页实际截图保留当前的数据不可用状态，未把演示行情写入公开数据。

这轮属于浏览器任务验证与视觉检查，没有开展真实用户 A/B 测试，也没有据此推断留存或转化提升。后续可让读者依次完成「找到一条要闻、筛出连板股票、读完研究后返回」三个任务，记录耗时和误操作。

## 重现交互检查

启动开发服务器后，在独立工具目录安装 `playwright-core@1.58.2` 和 `axe-core@4.10.3`，使用本机 Chromium。测试依赖无需加入生产安装。

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs \
AXE_SCRIPT=/absolute/path/to/axe-core/axe.min.js \
CHROMIUM_PATH=/usr/bin/chromium \
UX_BASE_URL=http://localhost:3000 \
node tests/browser/portal-ux.mjs
```

检查结果写入 `outputs/ux-v2/task-checks.json`，原型截图写入同目录。该目录不提交到 Git。
